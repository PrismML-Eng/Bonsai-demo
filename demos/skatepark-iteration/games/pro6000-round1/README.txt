Bonsai 2 skateboard game - PRO 6000 reproduction, round 1

Extract this ZIP and open skateboard.html in a modern browser.
Keep the vendor folder beside it. Three.js is included for offline use.
If opening the file directly is restricted by your browser, run:
  python3 -m http.server 8768
from this folder, then visit http://localhost:8768/skateboard.html

Controls: left/right arrows to roll; Space to jump; J backflip; K kickflip.
Click the page before using keys.
