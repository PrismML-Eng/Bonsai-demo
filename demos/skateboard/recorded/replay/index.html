Click the game, press Enter or Space to start. A / D or arrows steer, Space jumps.

Reproduce it

The recording used seed 42 on every request with the settings below. The agent reads the running game through a headless browser between turns, so its verification steps vary from run to run. The feedback rounds start from the previous round's file, which is copied into the working directory before the run.
