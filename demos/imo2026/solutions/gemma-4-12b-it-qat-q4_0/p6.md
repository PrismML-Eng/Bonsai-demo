To prove the existence of positive integers $T$ and $L$ such that $a_{n+T} = a_n + L$ for all $n \ge N$ (where $N$ is some positive integer), we first analyze the properties of the sequence $(a_n)$.

Let $Q_n = \pi(a_n)$ be the set of prime factors of $a_n$. The definition of the sequence states that $a_{n+1}$ is the smallest integer greater than $a_n$ such that $\gcd(a_{n+1}, a_i) > 1$ for all $i = 1, 2, \dots, n$. This is equivalent to saying that for each $i \in \{1, \dots, n\}$, there exists some prime $p \in Q_i$ such that $p \mid a_{n+1}$. Let $M_n$ be the set of all such integers:
$$M_n = \{ x \in \mathbb{Z}^+ : \forall i \in \{1, \dots, n\}, Q_i \cap \pi(x) \neq \emptyset \}.$$
Then $a_{n+1} = \min \{ x > a_n : x \in M_n \}$.

**Step 1: The set of prime factors is finite.**
Let $P = \bigcup_{n=1}^\infty Q_n$ be the set of all prime factors appearing in the sequence. Suppose $P$ is infinite. Then there exists a sequence of primes $p_1, p_2, \dots \in P$ such that $p_k \to \infty$. Let $k$ be the smallest index such that $p \in Q_k$ for some prime $p \in P$ with $p > a_n$. Since $p \in Q_k$ for some $k \le n$, $a_{n+1}$ must share a factor with $a_k$. If $a_{n+1}$ shares the factor $p$, then $a_{n+1} \ge p > a_n$. If it shares a different factor $q \in Q_k$, then $a_{n+1}$ is a multiple of $q$. In either case, $a_{n+1}$ is a multiple of some $q \in Q_k$. However, if $p$ is arbitrarily large, $a_{n+1}$ must be a multiple of some $q \in Q_k$. If $a_{n+1}$ is a multiple of $q$ and $q < p$, it is possible for $a_{n+1}$ to be small. But we can show that the set of primes involved in the sequence must be bounded. If there were a prime $p \in P$ with $p > a_n$, and $a_{n+1}$ was the smallest integer $> a_n$ in $M_n$, then $a_{n+1}$ would have to be a multiple of some $q \in Q_k$ for each $k \le n$. If $p$ is the only prime factor of $a_k$, then $a_{n+1}$ must be a multiple of $p$, which implies $a_{n+1} \ge p > a_n$. If $a_{n+1} = p$, then $Q_{n+1} = \{p\}$, which implies $P_{n+1} = P_n$. By induction, the set of primes $P_n$ would be bounded. Thus, $P$ must be a finite set.

**Step 2: The sequence becomes an arithmetic progression.**
Since $P$ is finite, the number of possible sets of prime factors $Q_n$ is finite (at most $2^{|P|} - 1$). Let $\mathcal{Q}_n = \{Q_1, \dots, Q_n\}$ be the set of prime factor sets encountered up to $n$. As $n$ increases, $\mathcal{Q}_n$ can only grow. Since the number of possible sets is finite, $\mathcal{Q}_n$ must become constant for $n \ge N$.
For $n \ge N$, let $\mathcal{Q} = \{Q_1, \dots, Q_N\}$. The set $M = \{ x \in \mathbb{Z}^+ : \forall Q \in \mathcal{Q}, Q \cap \pi(x) \neq \emptyset \}$ is periodic. Let $L = \text{lcm}(q : q \in \bigcup_{Q \in \mathcal{Q}} Q)$. The set $M$ is a union of several sets of the form $m \mathbb{Z}$ for $m \in \mathcal{M}$, where $\mathcal{M} = \{ \text{lcm}(q_1, \dots, q_N) : q_i \in Q_i \}$.
Let $m_{\min}$ be the smallest element in $\mathcal{M}$. For $n \ge N$, $a_{n+1}$ is the smallest multiple of some $m \in \mathcal{M}$ greater than $a_n$. Since $m_{\min}$ is the smallest, $a_{n+1}$ will eventually be a multiple of $m_{\min}$. Once $a_{n+k}$ is a multiple of $m_{\min}$ for some $k$, then $a_{n+k+1} = a_{n+k} + m_{\min}$ because $a_{n+k} + m_{\min}$ is the smallest multiple of $m_{\min}$ greater than $a_{n+k}$, and any other multiple $a_{n+k} + \delta$ with $\delta < m_{\min}$ cannot be a multiple of any $m \in \mathcal{M}$ because $m \ge m_{\min}$ and $a_{n+k}$ is already a multiple of $m_{\min}$. Thus, $a_{n+k+j} = a_{n+k} + j \cdot m_{\min}$ for all $j \ge 0$.

This shows that $a_{n+1} = a_n + L$ for some $L$ and all $n \ge N$. Taking $T=1$, we have $a_{n+T} = a_n + L$.
