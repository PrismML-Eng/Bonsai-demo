Reproduce it

One run, seed 42 on every request, min_p 0.05, with the settings below. The agent had no data: it fetched the 2026 knockout results from the web, saved them as JSON in ./data/ with null for anything it could not source, and wrote the page. The agent checks its page in a headless browser between turns, so its verification steps vary from run to run.
